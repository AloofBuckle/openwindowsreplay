PS7 Agent 是一个 Rust + egui 桌面程序，运行在 Windows Session 1（桌面会话）中。它发布 HTTP API，接收外部命令并透传给本机 PowerShell 7（pwsh.exe）执行。子进程继承 Session 1，可正常访问桌面资源（DDA/WGC 取帧、GUI 程序等）。
功能：从 SSH/远程主机执行需要桌面会话的 Windows 命令，解决 Session 0 隔离问题。
不接受非同网段连接，若使用代理需关闭或配置你的http连接工具为--noproxy
POST /run 流式
POST /run
Content-Type: text/plain  或  application/json
纯文本模式（命令直接作为 body）：
```bash
curl -sN http://<host>:<port>/run -d 'Get-Process | Select-Object -First 5'
```
JSON 模式（可指定超时）：
```bash
curl -sN http://<host>:<port>/run \
  -H "Content-Type: application/json" \
  -d '{"command":"Start-Sleep -Seconds 45; Write-Output done","timeout_ms":120000}'
```
响应
HTTP chunked transfer encoding，实时输出：
- stdout 行：原样输出
- stderr 行：以 `!STDERR: ` 前缀输出
- 最后一行：`!EXIT: code=0 duration=45259ms timed_out=false`
客户端必须加 `-N`（`--no-buffer`）参数**才能实时看到输出。
字段说明
| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| command | string | — | 命令字符串，传给 `pwsh -NoProfile -Command` |
| alias | string | — | 别名，查找别名表 |
| args | string[] | — | 直接透传给 pwsh.exe |
| stdin | string | null | 写入子进程 stdin |
| timeout_ms | uint64 | 600000 | 超时毫秒（默认 10 分钟） |
优先级：command > alias > args
POST /exec — JSON 非流式
```bash
curl -X POST http://<host>:<port>/exec \
  -H "Content-Type: application/json" \
  -d '{"command":"Write-Output Hello"}'
```
响应：
```json
{"exit_code":0,"stdout":"Hello\r\n","stderr":"","duration_ms":331,"timed_out":false}
```

```bash
curl http://<host>:<port>/health
```
